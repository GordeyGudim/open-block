# gostflow — блок-схемы по ГОСТ 19.701-90 из кода C++

Python-пакет: разбирает исходник C++ и строит блок-схему алгоритма
в обозначениях ГОСТ 19.701-90 (ISO 5807). Есть два способа работы:

- **CLI** — построить схему из файла в SVG/PNG;
- **локальный веб-интерфейс** — вставили код → посмотрели схему → скачали.

Работает офлайн: код никуда не отправляется.

> Примечание: в корне проекта лежит ещё одно, браузерное приложение на чистом
> JS (`index.html`, `js/`, `styles.css`) с собственным README. Этот пакет —
> независимая реализация на Python; они не зависят друг от друга.

## Требования

- Python 3.10+ (только стандартная библиотека — pip-зависимостей нет);
- **Graphviz** (`dot`) — используется только для позиций блоков:
  ```bash
  sudo apt install graphviz
  ```
- для PNG дополнительно один из:
  ```bash
  sudo apt install librsvg2-bin     # rsvg-convert (предпочтительно)
  # или
  sudo apt install imagemagick      # convert/magick (запасной вариант)
  ```

Graphviz и конвертер PNG — системные исполняемые файлы: в venv их не
ставят, пакет находит их через `PATH`. Без них соответствующие функции
аккуратно сообщают, что установить.

## venv и установка

Работать можно и без venv (зависимостей от pip нет), но правильнее — в
виртуальном окружении:

```bash
cd block
python3 -m venv .venv
source .venv/bin/activate
pip install -e .          # ставит пакет и консольную команду gostflow
```

После этого доступна команда `gostflow`:

```bash
gostflow samples/factorial.cpp --format both
gostflow --serve --open
gostflow --list samples/switch.cpp
python3 tests/smoke.py    # проверки
```

То же самое без активации: `.venv/bin/gostflow ...` или
`.venv/bin/python3 run.py ...`.

## Запуск

Без установки, из корня проекта:

```bash
python3 run.py samples/factorial.cpp                # SVG рядом с файлом
python3 run.py samples/factorial.cpp --format both  # SVG + PNG
python3 run.py samples/switch.cpp -o diag.png       # только PNG
python3 run.py samples/factorial.cpp - -o -.svg     # файл → stdout
python3 -m gostflow ...                             # то же самое
```

Основные ключи:

| Ключ | Назначение |
|---|---|
| `-o, --output` | файл результата (`.svg` / `.png`), `-` — stdout (SVG) |
| `--format svg\|png\|both` | формат (по умолчанию — по расширению) |
| `-f, --function ИМЯ` | какую функцию строить (по умолчанию `main`) |
| `--list` | показать найденные функции и выйти |
| `-t, --title ТЕКСТ` | заголовок над схемой |
| `--line-numbers` | номера строк кода рядом с блоками |
| `--serve` | запустить веб-интерфейс |
| `--host`, `--port` | адрес сервера (по умолчанию `127.0.0.1:8000`) |
| `--open` | открыть браузер после старта сервера |

Веб-интерфейс:

```bash
python3 run.py --serve --open
# http://127.0.0.1:8000/
```

ВASTE кода слева → «Построить» → схема справа; есть выбор функции, заголовок,
скачивание SVG и PNG (2×), горячая клавиша `Ctrl+Enter`.

Использование как библиотеки:

```python
from gostflow import generate_svg

svg, functions, selected = generate_svg(source, function="main", title="Факториал")
```

## Что поддерживается

- функции и методы (по функции строится отдельная схема, `--list` покажет все);
- `if / else if / else`, `?:` остаётся внутри выражений;
- `while`, `do/while`, `for` (обычный и range-for; `i` шаг рисуется отдельным
  блоком), `break`, `continue`;
- `switch/case/default`, включая проваливание (fallthrough) без `break`;
- `return` (несколько `return` сходятся в «Конец» отдельными стрелками);
- `try/catch` — показывается основной поток;
- ввод/вывод (`cin`, `cout`, `scanf`, `printf`, …) — фигура «данные»;
- вызовы функций и методов — фигура «предопределённый процесс»;
- комментарии и директивы препроцессора игнорируются;
- недостижимый код после `return`/`break` не попадает на схему.

## Обозначения (ГОСТ 19.701-90)

| Фигура | Значение |
|---|---|
| Скруглённый прямоугольник | «Начало», «Конец» |
| Прямоугольник | процесс: присваивания, вычисления, `break`/`continue` |
| Ромб | решение: условия, заголовки циклов, ветви `switch` |
| Параллелограмм | ввод/вывод |
| Прямоугольник с двойными стенками | вызов подпрограммы |
| Рёбра «Да»/«Нет» | выходы из решений |

Все линии ортогональные, стрелки на концах; обратные рёбра циклов
и боковые обходы идут снаружи схемы.

```
pyproject.toml    метаданные пакета (pip install -e .)
run.py            запуск без установки: python3 run.py ...
gostflow/
  lexer.py        токенизатор C++ (комментарии/препроцессор убираются)
  ast.py          дерево операторов
  parser.py       рекурсивный парсер + поиск функций
  flowchart.py    AST → граф вершин и рёбер (с классификацией фигур)

  render.py       SVG-отрисовка и PNG-конвертация
  api.py          публичный API (generate_svg)
  cli.py          командная строка
  web.py          локальный веб-интерфейс
samples/          примеры C++
tests/smoke.py    smoke-тест (python3 tests/smoke.py)
```

## Ограничения

- Подмножество C++: шаблоны, пространства имён, перегрузка операторов и прочие
  «взрослые» конструкции либо игнорируются, либо рисуются одним блоком.
- Метки `goto` не отслеживаются (метки пропускаются, поток строится по
  структуре).
- `try/catch` не разделяет потоки исключений.
- Раскладку делает Graphviz: положение блоков стабильное, но не всегда
  совпадает с ручной вёрсткой; при желании SVG можно доводить в редакторе.
